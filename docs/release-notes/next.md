# 下一版本更新说明（草稿）

> 发布流程会根据提交自动生成更新说明（`generate_release_notes`），用户在应用内看到的「更新公告」就是 GitHub Release 的说明。
> 打版本标签后，请把下面的内容粘贴到该 Release 的说明中，并把本文件改名为对应版本号存档（例如 `v1.1.0.md`）。

## 新功能

- **游戏兼容性改进**：按键改为以硬件扫描码发送，鼠标点击会按住约 30 ms，读取 DirectInput / Raw Input 或逐帧检测输入的游戏现在可以识别；以管理员身份运行后，不再误拦截受保护或带反作弊的游戏窗口。
- **游戏视角（相对移动）**：录制页可选择「游戏视角（相对移动）」记录鼠标原始位移，用于第一 / 第三人称游戏转动视角；脚本编辑器新增「视角移动」动作。
- **脚本快捷键**：在「脚本」列表中为常用脚本设置快捷键，在任何窗口按一下运行、再按一下停止（不倒计时）。
- **连点器开关快捷键**：在「设置 → 全局快捷键」中设置，按下即以连点器页面上次的设置开始，再按一次停止。
- **列表直接运行**：脚本列表和控制台「最近使用」中可一键运行 / 停止脚本。
- **按键 / 组合键动作**：编辑器中通过「点击后按键」设置按键，可一次插入 Ctrl+C、Alt+Tab 等组合键。
- **定时功能增强**：除了「等待一段时间」，还可以选「指定时刻」（例如每天 08:00:00），并可每天重复；到点时可以点击鼠标、按下按键或运行脚本。
- **脚本导入 / 导出**：脚本页可以把一个或多个脚本导出为 .json 文件分享，导入时自动校验并另存为新脚本。
- **托盘与置顶小窗**：关闭主窗口可以最小化到托盘继续运行；置顶小窗显示在游戏上方，随时查看进度、暂停、停止或急停。
- **暂停 / 继续快捷键**：在「设置 → 全局快捷键」中设置，对连点、定时、录制和回放都有效。
- **编辑器快捷键**：撤销 / 重做、Ctrl+S 保存、Delete 删除、Ctrl+C / Ctrl+V 复制粘贴动作。
- **记录 / 回到鼠标位置**（Issue #1）：脚本结尾加一个「回到记录位置」，运行完鼠标就回到启动前指着的地方。

## 体验改进

- 主题、「录制鼠标移动」和「最小记录间隔」重启后不再恢复默认。
- 状态栏显示实际正在运行的脚本，以及「开始回放」快捷键会运行哪个脚本；没有打开脚本时不再显示「已保存」。
- 顶栏只保留一个急停按钮，按钮上直接显示急停热键。

## 问题修复

- 停止录制后未保存就切换页面，录制结果会被清空 —— 现在会保留，直到保存或丢弃，侧边栏「录制」会显示提示点。
- 编辑器按键下拉框中的 Ctrl+C、Alt+Tab 等组合键选项无法回放，运行到该步骤时会中止 —— 已移除，改为组合键动作；旧脚本中的此类动作会在列表中标红，并在回放开始前提示具体是第几个动作。
- 修改录制得到的按键后，回放仍然按下原来的键 —— 已修复。
- 从列表或快捷键运行脚本时，状态栏显示的是编辑器里打开的脚本名 —— 已修复。

## 升级须知

- **行为变化**：「开始回放」快捷键现在按下即开始，不再先倒计时（与其他快捷键一致）；运行前倒计时只在点击按钮启动时使用。定时任务也不再额外倒计时，到点即执行。
- **建议不要降级**：新版本的设置文件增加了快捷键字段，降级回旧版本后会提示「本地设置文件无效」。如确需降级，请先备份并删除 `%USERPROFILE%\.keymouse-studio\settings.json`。
- 含「视角移动」「记录 / 回到鼠标位置」动作的脚本无法在旧版本中打开。
- 现在只能同时运行一个 KeyMouse Studio；再次打开会唤出已在运行（可能在托盘中）的窗口。
- 设为全局快捷键的按键会被系统级占用，在游戏里按下它不会再输入原来的内容，建议使用 F 键或 Ctrl / Alt 组合键。
- 游戏视角模式下，回放转动的角度取决于游戏内灵敏度，录制和回放时请保持相同设置。
